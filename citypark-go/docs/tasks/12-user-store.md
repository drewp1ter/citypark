## Table
```sql
CREATE TABLE users (
    id                   bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at           timestamptz NOT NULL DEFAULT now(),
    updated_at           timestamptz NOT NULL DEFAULT now(),
    name                 text NOT NULL,
    email                text UNIQUE,              -- NULL when the user has no email
    phone                text NOT NULL UNIQUE,     -- always "+7XXXXXXXXXX"
    password_hash        text NOT NULL DEFAULT '', -- bcrypt, '' when not set
    legacy_password_hash text NOT NULL DEFAULT '', -- hash from the old system, '' when not set
    role                 text NOT NULL DEFAULT 'user' CHECK (role IN ('user', 'admin')),
    is_email_confirmed   boolean NOT NULL DEFAULT false,
    is_phone_confirmed   boolean NOT NULL DEFAULT false
);
```

## Spec

```go
package user

type User struct {
    ID                 int64     `db:"id"`
    CreatedAt          time.Time `db:"created_at"`
    UpdatedAt          time.Time `db:"updated_at"`
    Name               string    `db:"name"`
    Email              *string   `db:"email"`
    Phone              string    `db:"phone"`
    PasswordHash       string    `db:"password_hash"`
    LegacyPasswordHash string    `db:"legacy_password_hash"`
    Role               string    `db:"role"`
}

// Response is the JSON shape of a user.
type Response struct {
    ID    int64  `json:"id"`
    Name  string `json:"name"`
    Email string `json:"email"` // "" when the user has no email
    Phone string `json:"phone"`
    Role  string `json:"role"`
}

func (u User) Response() Response

type CreateParams struct {
    Name         string
    Email        *string // nil = no email
    Phone        string
    PasswordHash string
    Role         string
}

type UpdateParams struct {
    Name  string
    Email *string // nil = remove the email
    Phone string
}

type Store struct{ db store.DBTX }

func NewStore(db store.DBTX) *Store

func (s *Store) Create(ctx context.Context, p CreateParams) (User, error)
func (s *Store) ByID(ctx context.Context, id int64) (User, error)
func (s *Store) ByEmail(ctx context.Context, email string) (User, error)
func (s *Store) ByPhone(ctx context.Context, phone string) (User, error)
func (s *Store) Update(ctx context.Context, id int64, p UpdateParams) (User, error)

// SetPasswordHash stores a bcrypt hash and clears legacy_password_hash.
func (s *Store) SetPasswordHash(ctx context.Context, id int64, hash string) error

// UpsertCustomer returns the user with this phone, creating it (role "user", no email,
// no password) when missing. An existing user gets the new name.
func (s *Store) UpsertCustomer(ctx context.Context, name, phone string) (User, error)
```

Rules:
- Keep one constant with the column list used by every `SELECT` and `RETURNING`:
  `id, created_at, updated_at, name, email, phone, password_hash, legacy_password_hash, role`.
- `Create`, `Update` and `UpsertCustomer` use `RETURNING <columns>` and scan with `GetContext`.
- `ByID`, `ByEmail`, `ByPhone`, `Update` return `store.ErrNotFound` when no row matches (wrap with `store.NotFound(err)`).
- `SetPasswordHash` returns `store.ErrNotFound` when no row was updated (`RowsAffected() == 0`).
- Unique violations are returned unchanged; callers check them with `store.IsUniqueViolation`.
- `UpsertCustomer` SQL:
```sql
INSERT INTO users (name, phone) VALUES ($1, $2)
ON CONFLICT (phone) DO UPDATE SET name = EXCLUDED.name, updated_at = now()
RETURNING <columns>
```

## Tests to write
All tests start with `db := testutil.NewDB(t)`.
- `TestCreateAndGet`: create with an email; `ByID`, `ByEmail`, `ByPhone` return the same user; `Response().Email` equals the email.
- `TestCreateNoEmail`: `Email: nil` → `Response().Email == ""`. Two users without email can coexist.
- `TestCreateDuplicatePhone` and `TestCreateDuplicateEmail`: the error satisfies `store.IsUniqueViolation`.
- `TestNotFound`: `ByID(999)`, `ByEmail("x@x.io")`, `Update(999, ...)`, `SetPasswordHash(999, "h")` give `store.ErrNotFound`.
- `TestUpdate`: changes name, email and phone; setting `Email: nil` removes the email; `UpdatedAt` is not before `CreatedAt`.
- `TestSetPasswordHash`: insert a user with `legacy_password_hash = 'old'` using plain SQL; after `SetPasswordHash` the user has the new hash and an empty legacy hash.
- `TestUpsertCustomer`: first call creates a user with role `user`; second call with the same phone and another name returns the same id with the new name; the table has one row.
- `TestStoreInTx`: inside `store.InTx`, `NewStore(tx).Create(...)` then return an error; the user does not exist afterwards.
