# Task 37: iiko menu/v3 client and menus table

## Goal

## Spec

### Migration `00002_menus.sql`
```sql
-- +goose Up
CREATE TABLE menus (
    id         bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    iiko_id    text UNIQUE,
    name       text NOT NULL
);
ALTER TABLE categories ADD COLUMN menu_id bigint REFERENCES menus (id);

-- +goose Down
ALTER TABLE categories DROP COLUMN menu_id;
DROP TABLE menus;
```
`menu_id` can be NULL: seed categories and categories made by hand have no menu. Do not change `internal/seed`, `internal/testutil` or `internal/catalog`.

### Types
Only the fields the service uses; unknown JSON fields are ignored.
```go
type Menu struct {
    ID          string        `json:"id"`
    Name        string        `json:"name"`
    ItemsGroups []ItemsGroup  `json:"itemsGroups"`
    Products    []MenuProduct `json:"products"`
}

type ItemsGroup struct {
    ID    string     `json:"id"`
    Name  string     `json:"name"`
    Items []MenuItem `json:"items"`
}

type MenuItem struct {
    ProductID  string          `json:"productId"`
    Name       string          `json:"name"`
    SizePrices []ItemSizePrice `json:"sizePrices"`
}

// ItemSizePrice: Price is nil when iiko sends no price; such an item is not for sale.
type ItemSizePrice struct {
    IsDefault bool     `json:"isDefault"`
    Price     *float64 `json:"price"`
    Weight    float64  `json:"weight"`
    SKU       string   `json:"sku"`
}

type MenuProduct struct {
    ID          string `json:"id"`
    SKU         string `json:"sku"`
    MeasureUnit string `json:"measureUnit"`
}
```

### Client
```go
// Menu downloads the external menu using the given token.
func (c *Client) Menu(ctx context.Context, token string) (*Menu, error)

// FetchMenu returns the external menu, managing the token itself (withToken).
func (c *Client) FetchMenu(ctx context.Context) (*Menu, error)
```

| Call | Request | Response handling |
|---|---|---|
| `Menu` | `POST {baseURL}/menu/v3/by_id`, `Content-Type: application/json`, `Authorization: Bearer <token>`, body `{"externalMenuId": "<externalMenuID>", "organizationId": "<organizationID>"}` | 200: decode `Menu`. 401: `ErrUnauthorized`. Other: `iiko: menu/v3/by_id: unexpected status <code>`. |

`FetchMenu` is built like `Fetch`: one `withToken` call around `Menu`.
