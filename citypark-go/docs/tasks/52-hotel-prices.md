database. The site reads them from `GET /hotel/prices`; an admin replaces them with `PUT /hotel/prices`.

### Routes
| Method | Path | Role | Behaviour | Success |
|---|---|---|---|---|
| GET | `/hotel/prices` | public | fees and breakfast items (by `sort`) | 200 |
| PUT | `/hotel/prices` | admin | replace fees and the whole breakfast list | 200 |

JSON (rubles):
```json
{"breakfastDelivery": 100, "lateCheckoutPerHour": 500, "smokingFine": 2000,
 "breakfast": [{"name": "Омлет, 130 г", "shortName": "Омлет", "price": 250, "desktopOnly": false}, ...],
 "updatedAt": "2026-10-22T12:00:00Z"}
```
PUT body: the same without `updatedAt`. Rules: the three fees required, 0–100 000, at most 2 decimals;
`breakfast` 0–30 items; `name` required ≤ 80 (trimmed); `shortName` ≤ 40; `price` required 0–100 000. The PUT runs in
one transaction: update `hotel_prices` (`updated_at = now()`), `DELETE FROM breakfast_items`, insert the items with
`sort` = position + 1. Response: the stored state.
