### Routes
| Method | Path | Role | Behaviour | Success |
|---|---|---|---|---|
| GET | `/news` | public | page of items, `date DESC, id DESC`, without `body` | 200 |
| GET | `/news/{slug}` | public | one item with `body` | 200 |
| POST | `/news` | admin | create | 201 |
| PUT | `/news/{id}` | admin | replace all fields | 200 |
| DELETE | `/news/{id}` | admin | delete, then remove its uploaded photo | 204 |

`GET /news` takes `page`/`pageSize` (`httpx.Pagination`) and returns `{"news": [...], "count": 7}`.
Item JSON: `{"id": 1, "slug": "...", "date": "2026-09-07", "title": "...", "shortTitle": "", "excerpt": "",
"body": "<p>…</p>", "photo": {"url": "", "alt": "", "position": ""}, "updatedAt": "..."}` (`body` only in the
single-item and admin responses). `photo.url` through `uploads.Public`.

POST/PUT body: `slug`, `date`, `title`, `shortTitle`, `excerpt`, `body`, `photo{url, alt, position}`. Rules (trim
plain strings): `title` required ≤ 200; `shortTitle` ≤ 100; `excerpt` ≤ 300; `date` `""` → today in the clock's
location, else `YYYY-MM-DD` (field `date`: `дата в формате ГГГГ-ММ-ДД`); `slug` `""` → `Slugify(title)`, else ≤ 100
and the pattern above (field `slug`: `только латиница, цифры и дефисы`); `body` → `richtext.Sanitize(Article, …)`,
`TextLength` ≤ 50 000; `photo.url` may be `""`, else `uploads.Stored` (`недопустимый адрес фото`); `photo.alt` ≤ 200;
`photo.position` as in task 48.

Slug conflicts: a slug given by the admin that already exists → 409 `Новость с таким адресом уже есть`. A generated
slug that exists gets `-2`, `-3`, … (first free one; check with a query before inserting, inside the transaction).
On PUT, the item's own slug is not a conflict. After PUT or DELETE commits, remove the replaced or deleted uploaded
photo (`uploads.Remove`, log errors). Unknown id or slug → 404.
