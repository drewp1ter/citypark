## Table
```sql
CREATE TABLE delivery_prices (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    name text NOT NULL UNIQUE,      -- town name; orders match address.city against it
    value text NOT NULL DEFAULT '', -- free description, e.g. "Россия, Краснодарский край, Сочи"
    price_kopecks bigint NOT NULL CHECK (price_kopecks >= 0)
);
```

## Spec

### `store.go`
```go
package deliveryprice

type DeliveryPrice struct {
    ID        int64         `db:"id" json:"id"`
    Name      string        `db:"name" json:"name"`
    Value     string        `db:"value" json:"value"`
    Price     money.Kopecks `db:"price_kopecks" json:"price"`
    CreatedAt time.Time     `db:"created_at" json:"createdAt"`
    UpdatedAt time.Time     `db:"updated_at" json:"updatedAt"`
}

type Input struct {
    Name  string        `json:"name" validate:"required,max=255"`
    Value string        `json:"value" validate:"max=255"`
    Price money.Kopecks `json:"price" validate:"gt=0"`
}

type Store struct{ db store.DBTX }
func NewStore(db store.DBTX) *Store

func (s *Store) Create(ctx context.Context, in Input) (DeliveryPrice, error)
func (s *Store) List(ctx context.Context) ([]DeliveryPrice, error) // ordered by id, never nil
func (s *Store) ByName(ctx context.Context, name string) (DeliveryPrice, error) // store.ErrNotFound
func (s *Store) Update(ctx context.Context, id int64, in Input) (DeliveryPrice, error) // store.ErrNotFound
func (s *Store) Delete(ctx context.Context, id int64) error // no error when the row is missing
```
All writes use `RETURNING id, name, value, price_kopecks, created_at, updated_at`.

### `handler.go`
```go
type Handler struct { /* db *sqlx.DB, tokens *auth.Tokens */ }
func NewHandler(db *sqlx.DB, tokens *auth.Tokens) *Handler
func (h *Handler) Routes(r chi.Router)
```
The handler takes `*sqlx.DB` because `POST` needs a transaction; build stores with `NewStore(h.db)` or `NewStore(tx)`.

| Route | Role | Behaviour |
|---|---|---|
| `GET /delivery-prices` | public | 200, `List` |
| `POST /delivery-prices` | admin | body `{"deliveryPrices": [Input, ...]}`; create all in one `store.InTx`; 201 with the created list |
| `PATCH /delivery-prices/{id}` | admin | body `Input`; 200 with the updated object; `ErrNotFound` → `httpx.NotFound()` |
| `DELETE /delivery-prices/{id}` | admin | always 204 |

```go
type createRequest struct {
    DeliveryPrices []Input `json:"deliveryPrices" validate:"required,min=1,dive"`
}
```
- Trim `Name` and `Value` before saving.
- A unique violation in `POST` or `PATCH` → `httpx.NewError(409, "name должно быть уникальным")`. In `POST` nothing is created when one item fails (the transaction rolls back).
- Register the public route outside the admin group:
```go
r.Get("/delivery-prices", httpx.Handle(h.list))
r.Group(func(r chi.Router) {
    r.Use(h.tokens.RequireRole(auth.RoleAdmin))
    r.Post("/delivery-prices", ...)
    ...
})
```
