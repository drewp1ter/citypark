## Tables
```sql
CREATE TABLE orders (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    customer_id bigint NOT NULL REFERENCES users (id),
    address_id bigint REFERENCES addresses (id) ON DELETE SET NULL,   -- NULL = pickup
    status text NOT NULL DEFAULT 'new' CHECK (status IN ('new','pending','paid','canceled','confirmed')),
    comment text NOT NULL DEFAULT '',
    payment_type text NOT NULL CHECK (payment_type IN ('cash','online')),
    items_hash text NOT NULL,
    payment_id text NOT NULL DEFAULT '',
    delivery_price_kopecks bigint NOT NULL DEFAULT 0
);
CREATE TABLE order_items (
    order_id bigint NOT NULL REFERENCES orders (id) ON DELETE CASCADE,
    product_id bigint NOT NULL REFERENCES products (id),
    amount integer NOT NULL DEFAULT 1 CHECK (amount > 0),
    offered_price_kopecks bigint NOT NULL CHECK (offered_price_kopecks >= 0),  -- price at order time
    PRIMARY KEY (order_id, product_id)
);
```

## Spec

### `types.go`
```go
package order

const (
    StatusNew = "new"; StatusPending = "pending"; StatusPaid = "paid"
    StatusCanceled = "canceled"; StatusConfirmed = "confirmed"
    PaymentCash = "cash"; PaymentOnline = "online"

type Customer struct {
    ID    int64  `json:"id"`
    Name  string `json:"name"`
    Phone string `json:"phone"`
}

type Address struct {
    ID      int64  `json:"id"`
    City    string `json:"city"`
    Address string `json:"address"`
}

type Item struct {
    OrderID      int64         `db:"order_id" json:"-"`
    ProductID    int64         `db:"product_id" json:"productId"`
    Name         string        `db:"name" json:"name"`
    CategoryName string        `db:"category_name" json:"categoryName"`
    Amount       int           `db:"amount" json:"amount"`
    OfferedPrice money.Kopecks `db:"offered_price_kopecks" json:"offeredPrice"`
}

type Order struct {
    ID            int64         `json:"id"`
    CreatedAt     time.Time     `json:"createdAt"`
    UpdatedAt     time.Time     `json:"updatedAt"`
    Status        string        `json:"status"`
    Comment       string        `json:"comment"`
    PaymentType   string        `json:"paymentType"`
    Total         money.Kopecks `json:"total"`         // sum of OfferedPrice * Amount, without delivery
    DeliveryPrice money.Kopecks `json:"deliveryPrice"`
    Customer      Customer      `json:"customer"`
    Address       *Address      `json:"address"`       // nil = pickup, JSON null
    Items         []Item        `json:"items"`         // never nil
    ItemsHash     string        `json:"-"`
    PaymentID     string        `json:"-"`
}

type ItemInput struct {
    ProductID int64 `json:"productId" validate:"gt=0"`
    Amount    int   `json:"amount" validate:"gt=0"`
}

// ItemsHash returns a stable hash of the items: sort by ProductID, join as "id:amount;",
// then hex(sha256). The order of the input does not matter.
func ItemsHash(items []ItemInput) string
```

Loading: read flat rows into an unexported struct, then convert to `Order`. Keep this `SELECT` (without a `WHERE`) in one constant; tasks 25b and 28 reuse it.
```sql
SELECT o.id, o.created_at, o.updated_at, o.status, o.comment, o.payment_type, o.items_hash, o.payment_id,
       o.delivery_price_kopecks,
       u.id AS customer_id, u.name AS customer_name, u.phone AS customer_phone,
       a.id AS address_id, a.city AS address_city, a.address AS address_text
FROM orders o
JOIN users u ON u.id = o.customer_id
LEFT JOIN addresses a ON a.id = o.address_id
```
`address_id`, `address_city`, `address_text` scan into pointers; all nil → `Order.Address == nil`.

Write one unexported method `(s *Store) loadItems(ctx, orders []Order) error` that fills `Items` and `Total` for a slice of orders with a single query (task 28 reuses it for lists):
```sql
SELECT oi.order_id, oi.product_id, p.name, c.name AS category_name, oi.amount, oi.offered_price_kopecks
FROM order_items oi
JOIN products p ON p.id = oi.product_id
JOIN categories c ON c.id = p.category_id
WHERE oi.order_id = ANY($1)
ORDER BY oi.order_id, oi.product_id
```
Deleted products and categories are still joined (an old order keeps showing its items).
