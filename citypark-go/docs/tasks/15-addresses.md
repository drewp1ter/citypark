## Tables
```sql
CREATE TABLE addresses (
    id bigint GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    created_at timestamptz NOT NULL DEFAULT now(),
    updated_at timestamptz NOT NULL DEFAULT now(),
    city text NOT NULL,
    address text NOT NULL,
    UNIQUE (city, address)
);
CREATE TABLE user_addresses (
    user_id bigint NOT NULL REFERENCES users (id) ON DELETE CASCADE,
    address_id bigint NOT NULL REFERENCES addresses (id) ON DELETE CASCADE,
    PRIMARY KEY (user_id, address_id)
);
```
An address row is shared: two users with the same city and street point to the same row. Removing an address for a user only removes the link.

## Spec

### `store.go`
```go
package address

type Address struct {
    ID        int64     `db:"id" json:"id"`
    City      string    `db:"city" json:"city"`
    Address   string    `db:"address" json:"address"`
    CreatedAt time.Time `db:"created_at" json:"createdAt"`
    UpdatedAt time.Time `db:"updated_at" json:"updatedAt"`
}

type Store struct{ db store.DBTX }
func NewStore(db store.DBTX) *Store

// FindOrCreate returns the address with this city and address text, creating it when missing.
func (s *Store) FindOrCreate(ctx context.Context, city, address string) (Address, error)

// LinkUser attaches the address to the user. Linking twice is not an error.
func (s *Store) LinkUser(ctx context.Context, userID, addressID int64) error

// UnlinkUser removes the link. It is not an error when the link does not exist.
func (s *Store) UnlinkUser(ctx context.Context, userID, addressID int64) error

// ListByUser returns the user's addresses ordered by address id. Never returns nil.
func (s *Store) ListByUser(ctx context.Context, userID int64) ([]Address, error)

// ByID returns store.ErrNotFound when missing.
func (s *Store) ByID(ctx context.Context, id int64) (Address, error)
```
SQL for `FindOrCreate` (one statement, safe under concurrency):
```sql
INSERT INTO addresses (city, address) VALUES ($1, $2)
ON CONFLICT (city, address) DO UPDATE SET updated_at = addresses.updated_at
RETURNING id, city, address, created_at, updated_at
```
SQL for `LinkUser`: `INSERT INTO user_addresses (user_id, address_id) VALUES ($1, $2) ON CONFLICT DO NOTHING`.

`ListByUser` must return `[]Address{}` (not nil) when there are none, so that JSON is `[]`.

### `handler.go`

func NewHandler(s *Store, tokens *auth.Tokens) *Handler

All three routes are behind `tokens.RequireRole(auth.RoleUser)`.

| Route | Behaviour |
|---|---|
| `GET /addresses` | 200, `ListByUser` of the signed-in user |
| `POST /addresses` | body below; trim both fields; `FindOrCreate` + `LinkUser`; 201 with the `Address` |
| `DELETE /addresses/{id}` | `httpx.PathID(r, "id")`; `UnlinkUser`; always 204 |
