# Публикация свободных номеров

1. В базе 1С с полными правами укажите константу `ХостПубликацииНомеров` как DNS-имя HTTPS-сервера (без схемы, порта и пути).
2. Укажите в `СекретПубликацииНомеров` значение серверного `HOTEL_WEBHOOK_SECRET`.
3. Включите `АвтоматическоеОбновлениеСайта`. В списке регламентных заданий проверьте, что включено одно задание «Обновление сайта» и его интервал равен пяти секундам. Проверьте расписание и в существующих информационных базах после обновления конфигурации.
4. Закройте рабочее место администратора и сравните ответ `GET /api/v1/hotel/rooms` со свободными номерами в 1С. Проверьте `updatedAt` и счетчик на главной странице после обновления кэша сайта.

Ошибки отправки видны в журнале регистрации по событию `Сайт.СвободныеНомера`. Следующий запуск повторит отправку. Для приостановки отправки отключите `АвтоматическоеОбновлениеСайта`.
